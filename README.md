# 待遇審議經濟指標

軍公教員工待遇調整審議參考指標儀表板（靜態網站）。

- `index.html`：儀表板網頁，開啟時讀取同目錄的 `data.json`，並可下載「軍公教員工待遇調整審議時參酌及相關參考指標彙整表」Excel 檔。
- `data.json`：指標與彙整表數據，由每日排程依行政院主計總處、國家發展委員會、財政部、台灣經濟發展研究中心等機關公布資料更新。
- `scripts/build_data.py`：由儀表板資料庫匯出檔產生 `data.json`。

本網站非官方發布，引用數據請以各機關原始公布為準。

### 主計總處新聞稿附表（D/E/F/H 經濟預測、J/K/L/M 薪資累計）
- `scripts/dgbas_fetch.py`（工作流程 `dgbas-probe.yml`，每日 10:15）：自主計總處新聞稿清單找最新「薪資及生產力統計」與「國民所得統計及國內經濟情勢展望」新聞稿，下載 `ws.dgbas.gov.tw` 上的 表1.ods／表2.ods／t1-1.ods 及新聞稿 PDF，輸出 `opendata/dgbas/latest.json`。
- D/E/F/H：新聞稿 PDF「重要經濟指標表」各年列（含 (f) 預測年）；J/L 年平均：表2 年累計÷12、表1 年平均；J/K/L/M 本年累計：表2「○年累計」÷月數、表1「○年1至○月」列、新聞稿「前○個月累計總薪資平均數較上年同期增加○%」。
- `parse_raw.py` 讀入為 `DG_<欄>`，`compare_raw.py` 規則：年資料不同→紅字(rev)；預測年只改第一行數字、保留其餘註記(fc)；累計數只在表值為累計口徑時更新並改寫期間註記(ver)；K/M 自動計算格不覆蓋。
